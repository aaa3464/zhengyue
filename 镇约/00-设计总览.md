# 《镇约》（暂名）· 设计总览 v0.1

> 一句话定位：**你是镇外坟场的守墓人。鬼杀不死——你只能把它们葬下去；而唯一能让鬼失效的办法，是让两只鬼的规则互相撞死。**

- 主角：**守墓人**（镇外坟场的看守者，镇民怕他、又不得不求他）
- 类型：单人 · 回合制 · 规则怪谈 / 恐怖卡牌策略
- 类比：杀戮尖塔的构筑节奏 + 暗黑地牢的压力 + 规则怪谈的"读规则再解题"
- 参考：《神秘复苏》（佛前献花，原名《恐怖复苏》）、《我的治愈系游戏》、《道诡异仙》、《诡秘之主》
- 状态：机制草案（未推演，数字全是初稿）

图例：✅ 已定 ／ ⚠️ 待定

## 2. 世界（一句话）

一个镇子被"律"围住：鬼是律长出来的，人必须照着规矩活，破例的人死。镇外坟场上住着守墓人——他手上有一把铁锹、一本镇志、一盏油灯，七夜之内能葬几只就葬几只，葬不住的，就让它们互相撞死。

## 2.5 主角：守墓人（已定）

**身份**：镇外坟场的看守者。镇上人与他保持距离，但死人时又不得不来求他——他既被需要，也被憎恶。这个张力是整个牌组的情绪底色。

**守墓人给了四个现成钩子（都接在已有系统上）**：

| 钩子 | 说明 | 接在哪 |
|---|---|---|
| **埋葬＝收容** | 鬼不是"揣进兜里"，而是葬进坟场坑位。坟场共 **6 个坑位**，每夜只能挖 1 个 | 容器系统改名「葬具」，并加场地维度 |
| **镇志＝读档＋情报** | 守墓人手上有一本镇志，每晚可"记名"镇上一个人——记下名字，就能提前看到他会以什么死法被律带走；但**被记名者更容易被鬼找到** | 第 6 条"退出保存"落地为翻镇志（铜镜放出一只鬼） |
| **坟场会渗律** | 每葬下一只，坟场就向镇子扩散一条它的律——**埋得越多，镇上越危险** | 与"清场越干净越危险"同一条轴 |
| **开坟夜＝终局** | 第 7 夜清算：你葬对的人/鬼留下，葬错的自己爬出来 | 7 夜收束，比"撑过 7 夜"有张力 |

**三件初始物**（对应书里的铁锹/柴刀/油灯）：
- **铁锹**：挖坑、断赐（毁赐物）各用一次／夜
- **镇志**：记名、读档；翻一次，铜镜里放出一只鬼
- **油灯**：照出"看不见的律"（把隐藏律显形一夜），点灯时鬼也看得见你

**由此改掉的三个名字**：行动力 → **三炷香**（每夜 3 炷，点完天黑）；规则真空 → **空坟**（那块地无律可依，人能走，鬼也能进）；收容成功 → **落葬**。

## 3. 一局的结构 ✅

| 项 | 数值 |
|---|---|
| 局长度 | **7 夜**（第 7 夜为开坟夜） |
| 每夜行动力 | **三炷香**（3 点，负面性会扣） |
| 镇民 | **30 人**（纯计数，不具名）⚠️ |
| 鬼 | **4 只**：律相 2 / 怨胎 1 / 傩嗣 1 |
| 坟位 | **6 个**（每夜只能挖 1 个） |
| 葬具 | **5 件**（手上同时持有 3 件）⚠️ |
| 牌库 | 25–30 张 ⚠️ |

**胜负**：熬过开坟夜且**落葬 ≥3 只** → 过关；镇民全灭 或 注视值满 5 → 败。

**一夜流程**：
1. 天黑 · 点起三炷香（抽牌 + 回满 3 点）
2. 布阵 · 打出「律」「葬具」「人」牌（每次行动 1 点）
3. 律结算 · 按 P 从高到低依次判定
4. 死人 / 落葬 / 吞并
5. 天亮 · 记死亡数、检查空坟、投喂傩嗣
6. 巡坟 · 选 1–2 座坟查看（不巡的坟可能长出未葬之鬼）
7. 负面性结算 · 扣除香或触发共情

## 4. 律系统 ✅（核心）

### 4.1 每条律三栏

```
律：触发条件 → 后果       P：生效率
```

**概率由律的"严格程度"决定，不由稀有度决定**（否则人人都要 100%，系统就废了）：

| P | 什么样的律 | 条件示例 |
|---|---|---|
| **100%** | 条件窄到几乎不可控，或每次触发自己也付代价 | "必须是第一个开门的人" |
| **90%** | 条件常见但可规避 | "夜里点灯的人"（绕黑路即可） |
| **70%** | 条件宽泛 | "任何夜里说话的人" |
| **50%** | 条件几乎无法规避，但效果必弱 | "全城起雾时惊醒的人"→ 只是昏睡 |
| **30%** | 广域环境律 | "镇上月起时走动的人"→ 丢影子，不死 |

> 概率 = **确定性与覆盖面之间的价格**。100% 贵在条件，30% 贵在范围。

### 4.2 对拼四步结算

两只鬼的律撞上同一目标（或玩家强行拉拢）：

1. **各自掷一次** `d100 ≤ P` → 该鬼"应战"；未应战者本轮完全静默
2. **只有一只应战** → 直接**压制**：胜者律照常，败者本夜失效
3. **两只都应战** → 算 `强度 = P + (RANK差 × 10)`：
   - 差 **> 20** → **吞并**（弱者消失，强者 `复苏+1`，可提纯一次）
   - 差 **11–20** → **压制**（弱者本夜＋下一夜失效，不消失）
   - 差 **≤ 10** → **死机**（双方永久失效，场地进入**规则真空**）
4. **都没应战** → **空振**（无事发生，两只鬼**复苏各+1**——"律落空了，鬼更饿了"）

**为什么死机看"差值小"而不是"两边都成功"**：死机要是可控工具，不能是运气赠品。想清场就挑两只 P 接近的鬼（70 vs 75），成本是三夜布阵＋一次真空风险。

**先手**：多鬼同场时 **P 高者先结算**。100% 律的隐性优势不是命中，而是**永远第一个杀人**。

### 4.3 三个附带规则

- **提纯**：吞并后可把一条软律转铁律（P +20），但负面性翻倍 → 养鬼路线 = 软律起家 → 吞并提纯 → 铁律坐镇。
- **五档锁死**：只准 30/50/70/90/100，不许 65/75 这种细颗粒（卡面会变 Excel，也算不过来）。
- **空振补偿**：同一只鬼连续两次空振后，本场 `P +15`（叙事是"它急了"）。

### 4.4 规则真空 ✅

- 死机后该场地成为真空：**人在里面可以自由行动**（安全），但律进不来
- 每夜结束掷一次：场上**死机 ≥3 只**时，引来 **0 级·不可收容鬼**（只能靠再造一次死机处理）
- 结论：**清场越干净，场上越危险。强度就是危险度。**

## 5. 三源体系 ✅

| | **怨胎**（情绪所生） | **律相**（规则所成） | **傩嗣**（大傩分赐） |
|---|---|---|---|
| 来源 | 活人情绪凝结 | 规矩自己长出鬼 | 上位"傩"把力量分下来 |
| 律从哪来 | **实时生成**：今夜谁哭，明早就有律 | **固定印在卡面**，可预判 | **借来的**，只写一半 |
| P 特性 | 波动（随镇民情绪 ±20） | **固定**，不飘 | 低而**可叠加**（多只合体提 P） |
| 成长 | 吸情绪：镇越绝望越强 | 守约杀人 | 归位／合体 |
| 收容 | 镇住**情绪源** | 改条件或断条件 | 切断**赐物** |
| 负面性 | **共情**：替它哭，每天 -1 行动 | **破例即偿** | **征召**：被上位借走一回合 |
| 死机倾向 | 只共振 | **唯一能死机的类** | 只寄生／合体 |

> **保护核心**：死机只能由律相参与。规则闭环才是真死机；怨胎只共振成一团更大的，傩嗣只会赖在规则缝里。你最初那套"规则对撞→死机"仍是战场中枢。

### 5.1 对撞矩阵（3×3）

| 撞上 | 怨胎 | 律相 | 傩嗣 |
|---|---|---|---|
| **怨胎** | **共振**：合体上涨，或烧到双死机 | 被**压制**，但会**污染**条件（"饮井水"→"心生渴念"，条件变宽） | 被**喂食**：怨胎情绪喂出傩嗣一条新律 |
| **律相** | 压制（规则不认眼泪） | **死机**（唯一入口） | **寄生**：钻进规则缝隙，规则清不掉它 |
| **傩嗣** | 喂食 | 寄生 | 同源**合体**；异源**征召**，不打架 |

### 5.2 三种"非杀戮清场"（补爽感）

| 类 | 怎么让它退场 | 代价 |
|---|---|---|
| 律相 | **制造死机** → 真空 | 真空引来 0 级；三夜内不能再用这块地 |
| 怨胎 | **让它吃干净**：把镇民情绪灌给它，灌满自散 | 那家人会疯／死；喂多了它反而变强 |
| 傩嗣 | **断赐**：毁掉赐物 | 上位注意到你（注视值 +1） |

三条路对应三种资源：**场地 / 人 / 风险值** → 自然分出三种流派。

### 5.3 配比（重要）

- 一局鬼 ≤4 只：**律相 2 / 怨胎 1 / 傩嗣 1**。律相少于 2，死机玩法就断了；傩嗣超过 1，寄生会失控。
- **别让怨胎变成免费燃料**：它喂出来的新律归傩嗣所有——"喂怨胎"是养敌，只在需要断赐或制造污染时才划算。这是三类体系里唯一容易失衡的地方。

## 6. 葬具（原容器）系统 ✅

> 守墓人不"收容"，他"落葬"。葬具 = 挖坑时配的东西，或坟场本身就有的旧物。

| 葬具 | 名额 | 能葬什么 | 取阅／代价 |
|---|---|---|---|
| **棺材钉** | 1 | 只钉**有实体**的鬼 | 无副作用（万用但稀缺） |
| **铜镜** | 1 | 无实体鬼 | **每翻一次镇志，放出一只** |
| **水缸** | 1 | 井/水相关的律相 | 缸水变浑，镇上三日无净水 |
| **买命钱** | — | 不葬，改为"送给一只鬼，它永不袭击你" | 那鬼不在落葬数里算分 |
| **棺材（红/黑）** | 1 | 濒死的人或休眠中的鬼 | 出棺即恶化（复苏+2） |

> 一律有**名额 / 条件 / 取阅代价**三栏（参照书里"棺材钉无论强弱只有一个名额"）。

## 7. 卡面示例

```
【律相】井中婆                        RANK 1
律：饮此井水者，七日内溺死             P 100%
条件：村里只有这一口井（窄而唯一，才配 100%）
收容：水缸（名额1）
负面：持卡者每夜必须说一句谎，否则咳血
死机：与另一条"互为闭环"的律相对撞
```

```
【怨胎】溺婴·小满                      RANK 1
律：今夜有人为亡者哭，哭声所及必溺一人   P 70%（±20 随镇上哀声）
条件：需要"哭声"——喂一个绝望的镇民即可
负面：持卡者每天替它哭一次（-1 行动）
消散：喂满 3 点哀恸 → 自行散尽（不留真空，但人会疯）
```

```
【傩嗣】无面送葬人·残                   RANK 2
律：（借自"送葬傩"）抬棺者不可回头       P 60%

负面：被上位借走一回合（弃一次行动）
断赐：毁其"引魂幡" → 退化为无律之物，可收容
```

## 8. 夜结算顺序（拟）

1. 点香（回 3 点 + 抽牌）→ 2. 记名／读档（自愿）→ 3. 出牌（律/葬具/人）→ 4. 按 P 从高到低结算律 → 5. 死人结算 → 6. 落葬／吞并 → 7. 空坟检查并掷骰 → 8. 傩嗣投喂 → 9. 巡坟 → 10. 负面性打卡

## 9. 三种流派

| 流派 | 打法 | 吃资源 |
|---|---|---|
| **布阵流** | 摆两只 P 接近的律相制造死机，靠真空清场 | 场地、三夜周期 |
| **牧人本流** | 喂怨胎到散、推镇民踩线换收容 | 人（镇民就是弹药） |
| **盗物断赐流** | 找赐物、断赐，把傩嗣打成无律之物再收 | 风险值（注视） |

## 10. 待你拍板的 5 件事 ⚠️

1. ~~**你的立场**~~ → ✅ **已定：守墓人**（收容派，靠葬与记名推进；可养鬼但会脏手）
2. **鬼怎么进场**：开局固定 4 只，还是每夜从牌库摸？前者像解谜，后者像构筑。
3. **镇民要不要具名**：抽象人口计数（快、冷）vs 具名有关系的镇民（慢、痛）。这决定游戏是"策略"还是"叙事"。
4. **读档机制**：已经绑上镇志（翻一次放出一只鬼）。当核心玩法还是只当便利？核心的话"退出保存"要变成每夜的一个决策点。
5. **单局时长**：30 分钟（夜短、牌少）／60 分钟（标准）／90 分钟（长线）。
6. **尺度**：血腥描写到哪一步（影响美术方向和文案调性）。

## 11. 设计风险清单

| 风险 | 已埋的对策 |
|---|---|
| 刷死机清场 | 真空 + 引来 0 级鬼 + 三夜冷却 |
| 鬼不可杀 → 缺清场爽感 | 移交/封存/沉眠三出口，各有资源回报 |
| 概率挫败（布好阵却掷空） | 连续空振 P+15 |
| 规则文本爆炸 | 律 ≤12 字、活跃律 ≤5、容器只 4 种 |
| 三类失衡 | 怨胎喂出的是傩嗣的律（养敌），配比锁死 2:1:1 |
| 死机变成唯一解 | 真空危险度随死机数指数上升 |
