# 《镇约》· 精简规则 v0.2

> 目标：一页能讲完，30 分钟一局，靠氛围和"撞律"爽感打人。v0.1 那套完整版另存，当"深度模式"或日后 DLC。

## 一句话

你是镇外坟场的守墓人。鬼杀不死，但能葬；唯一让鬼失效的办法，是让两只鬼的规则**撞死**。

## 一局的数字

| 项 | 值 |
|---|---|
| 夜数 | **5 夜** |
| 每夜行动 | **3 点** |
| 镇上人 | **12 人**（死了就是死了，不回补） |
| 鬼 | **3 只**（开局全在场，位置随机） |
| 葬具 | **3 件**（铁锹、铜镜、棺材钉各一） |
| 牌库 | **18 张**（律卡 9 / 人卡 5 / 葬具卡 3 / 事件 1） |

**输**：12 人死光。**赢**：第 5 夜结束还剩 ≥4 人，且至少葬下 1 只。葬下 2 只 = 真结局。

## 鬼卡只有三行

```
【律相】井中婆
律：喝过村口井水的人，七日内溺死    P 100
律值：2
```

只有三样：**律（条件→后果）**、**P（30/50/70/100）**、**律值（1–3）**。没有位阶、没有矩阵、没有复苏条。

## 每夜就三个动作

1. **推人**：把一个人推到某条律的条件上（"让她去井边打水"）
2. **引鬼**：把一只鬼引到一个地点（"把送葬人引到祠堂"）
3. **下葬**：用一件葬具收一只**已死机**的鬼

行动力不够，所以每夜真正的决策是：**今晚是让人死，还是把鬼撞死。**

## 结算（全部在一分钟内）

1. **杀**：所有律各掷一次，`d100 ≤ P` 就杀一个人。没人踩线就没人死。
2. **撞**：两只鬼在同一处 → 比**律值**。
   - 高者留，低者本夜失效
   - **律值相同 → 双双死机**，永久失效，那块地变**空坟**
3. **空坟**：无律可依之地。人能自由走，鬼也能进——鬼会挤过来，下一夜这里可能同时有两只鬼。
4. **葬**：死机的鬼才可以下葬。下葬后坟场向镇上扩散一条它的律（埋越多镇越危险）。

## 三源只保留一句话

- **律相**：P 固定，可撞死机
- **怨胎**：P 每夜随机 ±20，**撞不出死机**（只能被压制）
- **傩嗣**：撞输后会**寄生**在赢家身上——赢家从此"恶名+1"，但律也跟着它走

（不做 3×3 矩阵。三类各一句，玩家 10 秒能记住。）

## 卡面长这样

```
【怨胎】溺婴·小满              P 70（±20）
律：有人为亡者哭，哭声所及必溺一人
律值：1
```

```
【葬具】棺材钉
效果：葬一只"有实体"的鬼。每局只有一次。
```

```
【人】打水的阿秀
标签：会照做／有亲属
效果：指向她时，可无视距离触发一次"水"相关条件
```

## 一局 30 分钟的样子

- 第 1 夜：认识三只鬼的律，试推一个人（大概率死一个，学会"条件"）
- 第 2 夜：第一次尝试引鬼对撞，发现律值不对（撞输，学"律值"）
- 第 3 夜：凑出第一次死机，葬下第 1 只（爽点）
- 第 4 夜：坟场扩散出的律开始杀镇上人（代价浮现）
- 第 5 夜：空坟里挤了两只鬼，做最后的选择（葬一只 / 保人）

## 与 v0.1 的取舍

| 砍掉 | 原因 |
|---|---|
| 五档概率 + 差值三档 | 一局要掷太多次、算太多，新手前 10 分钟就劝退 |
| 位阶 RANK / 提纯 | 数值层数太多，收益不明显 |
| 6 坟位 / 巡坟 / 注视值 | 三个都是"记账"动作，没有即时反馈 |
| 三源 3×3 矩阵 | 9 格玩家记不住，改成三类各一句 |
| 7 夜 / 30 人 / 25 张牌 | 缩短到 5 夜 / 12 人 / 18 张，一局能跑完 |

**保留**（这才是卖点）：鬼不可杀只能葬、规则杀人、**两鬼撞死机**、守墓人身份与镇志。
